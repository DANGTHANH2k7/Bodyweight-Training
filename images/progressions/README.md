# Progression exercise images

The exercise detail screen looks for per-exercise images here:

`images/progressions/{category_id}/{exercise-slug}.jpg`

Examples:

- `images/progressions/squat/assisted-squats.jpg`
- `images/progressions/squat/deep-assisted-squats.jpg`
- `images/progressions/pull_up/leg-assisted-pull-ups.jpg`
- `images/progressions/push_up/wall-push-ups.jpg`
- `images/progressions/plank/kneeling-plank.jpg`

The workout list cards still use the broader images in `images/workouts/`.
